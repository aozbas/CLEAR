# hosted_database/

Hosted database project config, SQL migrations, and seed data — managed by the [Hosted database CLI](https://hosted_database.com/docs/guides/cli).

## Layout
```
hosted_database/
├── README.md
├── config.toml          # generated by `hosted_database init`
├── migrations/          # timestamped SQL migration files
│   └── 0001_init.sql
└── seed.sql             # local-dev seed data
```

## Common commands
```bash
hosted_database init            # one-time, creates config.toml
hosted_database start           # local Postgres + Studio + Auth
hosted_database db reset        # re-apply all migrations + seed
hosted_database migration new <name>
hosted_database db push         # push migrations to the linked remote project
```

## Conventions
- Migrations are append-only. Never edit a migration that's been pushed — write a new one.
- Keep `seed.sql` to development-only fixtures. No real user data.
- Schema summary lives in [../docs/db-schema.md](../docs/db-schema.md).
